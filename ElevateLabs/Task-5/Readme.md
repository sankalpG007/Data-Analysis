# 🚢 Titanic Dataset - Exploratory Data Analysis (EDA)

This project is part of my Data Analyst Internship - **Task 5: EDA**.  
The objective was to explore a dataset visually and statistically to extract meaningful insights and patterns.

## 📂 Dataset
- Dataset used: [Titanic Dataset](https://www.kaggle.com/c/titanic/data?select=train.csv)
- Contains details of passengers such as Age, Sex, Class, Fare, and whether they survived.

## 🛠 Tools Used
- Python
- Jupyter Notebook
- Libraries:
  - `pandas` for data manipulation
  - `matplotlib` and `seaborn` for data visualization

## 🔍 What I Did
- Loaded and cleaned the Titanic dataset
- Performed basic data exploration using `.info()`, `.describe()`, and `.isnull().sum()`
- Conducted:
  - **Univariate Analysis** (Age, Gender, Fare, etc.)
  - **Bivariate Analysis** (Survival vs Gender, Class)
  - **Multivariate Analysis** (using pairplot and heatmap)
- Visualized key trends using bar plots, histograms, boxplots, heatmaps, and pairplots
- Documented **insights and observations** under each visual
- Summarized findings at the end of the notebook

## 📈 Key Insights
- Females and 1st class passengers had higher survival rates
- Higher Fare and lower Pclass were positively correlated with survival
- Most passengers were young adults between 20–40 years
